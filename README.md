# AltBot (Fabric 1.21.11)

Budowanie: Java 21 + Gradle (`gradle wrapper` jednorazowo, potem `./gradlew build`).
Gotowy plik: build/libs/altbot-0.1.0.jar -> do folderu mods (wymaga Fabric Loader + Fabric API 1.21.11).

Uzycie: przycisk "AltBot" na ekranie tytulowym / liscie serwerow albo komenda /altbot.
